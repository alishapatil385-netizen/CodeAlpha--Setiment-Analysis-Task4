# CodeAlpha--Setiment-Analysis-Task4
**Amazon Reviews Sentiment Analysis**
**Project Overview**

This project performs Sentiment Analysis on Amazon customer reviews using Python and NLP techniques. Reviews are classified into Positive, Neutral, and Negative categories based on ratings and sentiment patterns.

**Objective**
Analyze customer reviews from Amazon products.
Classify sentiments as Positive, Neutral, or Negative.
Visualize sentiment distribution using charts and word clouds.
Generate insights about customer satisfaction.
